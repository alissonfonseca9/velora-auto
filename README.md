# VELORA

Site conceitual de uma marca fictícia de veículos elétricos, criado para estudo. Apresenta os modelos S9 e X7 em uma experiência responsiva e interativa.

## Executar

Abra `dist/index.html` no navegador ou sirva a pasta `dist` com um servidor HTTP local.

## Tecnologias

HTML5, CSS3 e JavaScript, sem dependências de instalação. As imagens fornecidas estão em `dist/assets`.

Projeto demonstrativo, sem vínculo com fabricantes reais.
